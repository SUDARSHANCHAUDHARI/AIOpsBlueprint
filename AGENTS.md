# AIOpsBlueprint Agent Notes

AIOpsBlueprint is a documentation-first blueprint for building, operating, and governing AI-powered engineering systems.

## Working Rules

- Keep this repo content-first: docs, playbooks, prompts, templates, and examples.
- Do not add CI/CD unless explicitly requested.
- Do not commit generated archives, `.env`, local config, secrets, credentials, or personal agent config.
- Prefer useful concrete playbooks over broad placeholder sections.

## Product Scope

- MVP priority: make each top-level area useful with practical checklists, templates, and examples.
- Defer automation tooling until the written blueprint has a clear structure and audience.
